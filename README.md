# NED3 Core VI

Public raster reference package for the NED3 research-software visual identity systems.

The site is published with GitHub Pages from this repository and presents the
approved packaged PNGs for each system. Every displayed asset has its own
download link, including the primary lockup, icon PNG, logo-system board, and
application visual where one is part of that system. Data Center Atlas includes
its approved light and dark lockups, color and monochrome icons, system board,
and app-icon proof.

## Included systems

- AELab
- BoilingLab
- BubbleID-Flow
- Data Center Atlas
- Data Center Cooling Research Tools
- FlowLab
- OpenDC-LCA
- RetailFlex-Open
- Thermal AI Commons

## Asset status

The files are approved raster reference assets, not editable vectors, font
files, trademark clearances, or evidence for claims beyond the underlying
software. Use Manrope separately for production typography. Preserve the mark
geometry, contrast, clear space, and color relationships. The icon PNGs for
the eight original Core VI systems are deterministic crops from their approved
primary-lockup rasters; Data Center Atlas includes its separately approved
icon artwork.

Run `py -3.12 scripts\\export_icon_assets.py` after replacing an original
Core VI `primary-light.png` to refresh its icon crop.
